Valkey
-----

 Valkey 는 https://github.com/valkey-io/valkey 에서 운영하는 오픈소스 인메모리 NoSQL 입니다.


진행방법
-------

 * 컨트리뷰션 자체보다는 git 과 Valkey 의 이해에 대해서 초점을 맞춥니다. 
 * 모임때에 각자 자신이 준비한 내용을 발표하는 형태와 간단한 세미나로 진행합니다.
